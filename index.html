LearnPlace value2 min

A digit has a job.

The same digit can have a different value in a different place.

Digit

A symbol: 0, 1, 2, 3, 4, 5, 6, 7, 8 or 9.

Place

The position of a digit in a number.

Value

How much that digit is worth in its place.

347
300 + 40 + 7 = 347
In 347, the digit 4 is in the tens place. Its value is 40.

Every place has a value.

A place-value chart is a map, not a memory test.

Tap or click a column. Each place to the left is worth 10 times as much. A dash means the place is not used.

Read the places from the right: ones → tens → hundreds → thousands → ten thousands → hundred thousands → millions.
